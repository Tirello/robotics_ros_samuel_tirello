# Docker

Atividades de Docker: conteinerizacao do ambiente de desenvolvimento usado em robotica.

## Listas

Nenhuma atividade entregue ate o momento. Cada atividade entra como uma pasta
`Lista N - Assunto`, com um README proprio descrevendo os arquivos e como executar.

## Como rodar

O comando depende da atividade e fica documentado no README de cada lista. Em geral:

```bash
docker build -t <nome-da-imagem> .
docker run --rm -it <nome-da-imagem>
```
